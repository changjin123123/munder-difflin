# 보물공방 Windows 통합판

통합판 상단에는 **트레이딩 사무실**과 **보물공방** 두 탭이 있습니다. 회의에서 마이클의 최종 판정을 확인하고, 보물공방에서 빗썸 원화 현물과 빙엑스 USDT 무기한선물의 시세, 최신 뉴스, 모의 장부를 조회합니다. **전체 종목 모의 시작**과 **모의 중지**는 두 거래소를 함께 제어합니다. 장부의 현금과 손익은 KRW와 USDT로 나누어 표시합니다. 처음 실행하면 앱 데이터 폴더에 회의 작업공간을 준비하며, 기존에 지정한 작업공간이 있으면 그 폴더를 사용합니다.

Windows 배포 파일에는 Python과 보물공방 엔진이 들어갑니다. 마우스로 보물공방을 열면 엔진이 백그라운드에서 시작되며, 모의매매는 버튼을 눌렀을 때 시작합니다. 통합판이 소유한 엔진은 통합판 종료 시 감시를 중지하고 장부를 보존합니다. 통합판은 자체 Munder 설정 폴더를 사용합니다.

**트레이딩 사무실 → 뉴스 브리핑과 토론**에서 회의가 수집한 최근 24시간의 종목·시장 기사를 확인할 수 있습니다. 켈리가 블록미디어와 CoinDesk의 제목과 RSS 요약을 사건별로 묶습니다. 강세·약세 연구원과 마이클의 자막 옆 출처를 누르면 원문이 열립니다. 관련 기사, 사건 종합, 토론과 최종 심사의 인용이 확인되어야 회의 전용 장부에 모의 진입할 수 있습니다. 뉴스 기능 추가 전에 저장한 회의는 당시 기록으로 재생됩니다.

회의 순서는 Xiao 등의 [TradingAgents 원 논문 4절](https://arxiv.org/html/2412.20138v7)에서 가져왔습니다. 이 앱의 캐릭터와 엔진으로 구현하며, 분석과 강세·약세 토론 뒤 필리스가 계획을 제안합니다. 공격적·보수적·중립 심사역은 같은 계획과 앞선 의견을 차례로 검토하고, 케빈이 근거를 대조한 뒤 마이클이 결정합니다. 제안 가격은 당시 거래소 호가로 계산하고 승인된 모의 체결은 새 호가로 기록합니다.

### 빌드

1. 이 포크의 Node 20 및 Windows x64 Electron 32.3.3 의존성을 설치합니다. Electron과 호환되는 node-pty 및 better-sqlite3 바이너리가 필요합니다.
2. Windows x64 Python 3.12(Tk 포함)에서 `python tools/stage-treasure.py BOT_SOURCE.zip .treasure-stage`를 실행합니다. ZIP에는 최상위 폴더 하나와 `office_host.py`가 포함된 보물공방 소스가 있어야 합니다. 개인 데이터와 계정 설정은 포함하지 않습니다. 준비한 비공개 자산은 Git에서 제외됩니다.
3. `npx electron-vite build --mode treasure`, `npm run copy:main-assets`, `npx electron-builder --win portable --x64 --config electron-builder.treasure.yml --publish never`를 차례로 실행합니다. `treasure` 모드는 트레이딩용 화면만 묶습니다.

기본 장부 위치는 통합판 Electron userData 아래의 `treasure-engine/data`입니다. 기존 장부를 사용할 때는 같은 userData의 `treasure-location.json`에 `{"directory":"기존 보물공방 폴더의 절대 경로"}`를 저장한 뒤 앱을 다시 엽니다. 기존 보물공방이 그 장부를 사용 중이면 같은 Windows 사용자의 인증된 모의 전용 로컬 연결을 사용합니다. 화면에서 거래소 API 키를 요구하지 않습니다.
